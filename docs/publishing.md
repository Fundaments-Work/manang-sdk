# Publishing a plugin

Listing a plugin in the Manang registry is documented in the
`manang-plugins-registry` repository: see `docs/publishing.md` there (the steps
to prepare the manifest, build the `.manangplugin`, create a GitHub release and
open a pull request that adds `plugins/<id>.toml`, plus what reviewers check).

This page is a pointer only. The publishing guide was imported on 2026-10-20 into
that repository and is being restructured; the registry repository is the single
place it is maintained.
